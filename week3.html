3회차. 교실 적용 결과 공유와 다음 단계

써 본 결과로 한 번 더 고치고, 서로의 앱을 열어 봅니다.

분활동
0~5오프닝: “써 본 결과로 한 번 더 고치기”
5~20적용 결과 공유(1인 1분) → 고칠 점 1가지 수정·재배포
20~30문제 해결: 404, 빈 화면, 반영 지연 (문제 해결)
30~45서로 사용해 보기: 주소를 공유 문서에 적고 피드백 1줄
45~55다음 단계 안내 (다음 단계)
55~60마무리 설문, 사후 지원 안내

참가자별 주소 목록은 이 사이트가 아니라 별도 공유 문서에 적습니다. 링크는 참가자에게 개별로 안내합니다.

꼭 지켜 주세요 학생 개인정보(이름·번호·평가 결과)와 API 키·비밀번호는 앱 코드와 저장소에 넣지 않습니다. GitHub Pages는 공개 주소이고, 배포하면 코드 전체가 누구에게나 보입니다.

3회차. Google Antigravity로 내 앱 고치기

개인 Google 계정으로 Antigravity를 사용해 기존 앱을 열고, 원하는 부분을 수정한 뒤 결과를 확인합니다.

오늘의 흐름

분활동
0~10개인 Google 계정으로 Antigravity 시작하기와 화면 익히기
10~20기존 앱 폴더 열기 → AI에게 앱 설명과 실행 방법 물어보기
20~40고치고 싶은 점 한 가지를 요청하고 실행해서 확인하기
40~50결과가 다르면 다시 요청하고 오류 해결하기
50~55연결된 GitHub 저장소 확인 후 수정 내용 반영하기
55~60고친 점과 다음에 해 보고 싶은 점 나누기

준비물

  • 개인 Google 계정과 GitHub 계정
  • 기존 앱이 저장된 컴퓨터
  • 앱에서 고치거나 추가하고 싶은 점 한 가지

이렇게 실습합니다

  1. Antigravity에서 기존 앱 폴더를 열고 앱을 실행해 현재 모습을 확인합니다.
  2. AI에게 현재 모습과 바꾸고 싶은 점, 기대하는 결과를 설명합니다.
  3. 수정한 앱을 직접 실행합니다. 원하는 대로 작동하지 않으면 나타난 상황을 알려 주고 다시 요청합니다.
  4. 어느 GitHub 저장소에 연결되어 있는지 확인하고 수정 내용을 반영한 뒤, GitHub에서 확인합니다.

실습 예시: 잘못된 그림 고치기, 게임에 선택 기능 추가하기, 연산 연습 문제 만들기

처음 요청해 보기 이 폴더는 제가 만든 수업용 앱입니다. 아직 코드를 수정하지 말고, 이 앱이 어떤 기능을 하는지와 제가 직접 실행해서 확인하는 방법을 한국어로 쉽게 설명해 주세요.

영어 메뉴가 낯설어도 괜찮습니다. 오늘 필요한 화면부터 함께 살펴보고, 각자의 속도에 맞춰 실습합니다.

꼭 지켜 주세요 학생 개인정보(이름·번호·평가 결과)와 API 키·비밀번호는 앱 코드와 저장소에 넣지 않습니다. GitHub Pages는 공개 주소이고, 배포하면 코드 전체가 누구에게나 보입니다.

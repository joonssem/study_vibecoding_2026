도구 안내

이번 연습에서는 index.html 한 파일로 실행되는 웹앱을 사용합니다.

AI와 만든 코드를 파일로 보관하면 나중에 다른 편집 도구나 AI 도구에서 열어 수정할 수도 있습니다. 앱에 별도 파일, 외부 서비스나 서버가 필요하다면 실행과 배포에 추가 설정이 필요합니다.

1회차 주요 도구: Google AI Studio

Google AI Studio의 Build에서는 원하는 앱을 말로 설명하고 미리보기를 살펴보며 대화로 고칠 수 있습니다. Explore의 대화 화면은 모델과 설정을 바꿔 응답을 실험할 때 활용합니다. 처음에는 기본 설정으로 시작해도 됩니다.

Build는 여러 파일을 사용하는 웹 프로젝트를 만들 수 있습니다. GitHub에 프로젝트를 저장하는 것과 GitHub Pages에 실행 가능한 결과물을 배포하는 것은 별개입니다. 이번 실습은 서버나 API 키 없이 동작하는 단일 HTML을 요청하고 확인한 뒤 배포합니다. Google AI Studio에서 Cloud Run으로 공개하는 방법도 있지만 계정 조건과 비용을 확인해야 하므로 이번 실습에서는 다루지 않습니다.

자세한 내용은 Google의 Build 안내와 배포 안내를 참고하세요.

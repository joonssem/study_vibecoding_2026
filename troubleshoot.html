문제 해결

막히면 먼저 아래를 순서대로 확인해 보세요.

주소를 열었더니 404가 나와요

  • 아직 반영 중일 수 있습니다. 2분쯤 기다렸다가 다시 엽니다.
  • 저장소가 Public인지 확인합니다.
  • Settings → Pages에서 Branch가 main으로 저장되어 있는지 확인합니다.
  • 주소의 아이디와 저장소 이름에 오타가 없는지 확인합니다.

화면이 하얗게 비어 있어요

  • 붙여넣은 코드가 끝까지 들어갔는지 확인합니다. 중간에 잘리면 빈 화면이 됩니다.
  • 코드 맨 앞과 맨 뒤에 설명 문장이나 ``` 표시가 붙어 있지 않은지 봅니다.
  • 그래도 안 되면 오류 문구와 원하는 동작을 그대로 AI에게 붙여 넣고 고쳐 달라고 합니다.

고쳤는데 화면이 그대로예요

  • Ctrl+Shift+R로 강력 새로고침을 합니다.
  • Commit을 눌렀는지 확인합니다. 저장소 첫 화면에서 방금 시간이 보여야 합니다.
  • 보통 수십 초, 길게는 1~2분 기다립니다.

파일 이름이 틀렸어요

  • 파일 이름은 index.html이어야 합니다. Index.html, index.html.txt, index (1).html은 안 됩니다.
  • 저장소에서 파일을 열어 연필 아이콘 옆 이름 부분에서 이름을 고칠 수 있습니다.

AI에게 이렇게 말해 보세요

막힌 문구 그대로 붙여 넣기 “아래 오류가 나옵니다. [오류 문구]. 원하는 동작은 [~하면 ~가 되는 것]입니다. 고친 전체 코드를 주세요.”
꼭 지켜 주세요 학생 개인정보(이름·번호·평가 결과)와 API 키·비밀번호는 앱 코드와 저장소에 넣지 않습니다. GitHub Pages는 공개 주소이고, 배포하면 코드 전체가 누구에게나 보입니다.

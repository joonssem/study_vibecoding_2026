1회차. 내 앱을 인터넷 주소로 열어 보기

2026년 11월 10일 (화) 15:00~16:00 · 5-2 교실

AI와 대화하며 만든 코드나 준비된 예시를 파일로 저장하면 직접 보관하고 수정할 수 있습니다. GitHub에 저장한 뒤 Pages로 배포하면 학생과 동료가 브라우저에서 열어 볼 수 있습니다. 수업에서 써 본 뒤에는 고친 내용을 같은 주소에 다시 반영할 수 있습니다.

만들기 → 파일로 저장하기 → 공개 주소로 열기 → 사용하고 개선하기
GitHub에 파일을 저장하는 것과 Pages로 공개하는 것은 서로 다른 단계입니다. Commit은 변경 내용을 기록합니다.

오늘 함께 할 일 ① Google AI Studio에서 교실용 앱을 만들어 보거나 예시 앱을 고릅니다.
② 전체 코드를 GitHub의 index.html에 붙여넣습니다.
③ 공개 주소로 열고, 글자 하나를 바꿔 다시 확인합니다.

준비 확인: Google AI Studio에서 사용할 수 있는 구글 계정과 GitHub 로그인을 확인하세요. 학교 계정은 관리자 설정에 따라 사용이 제한될 수 있습니다. 막히면 손을 들어 주세요. 함께 해결하겠습니다.

첫 모임 전에: GitHub 가입 안내 펼쳐 보기

첫 모임 전에: GitHub 가입하기

11월 9일까지 무료 계정을 만들어 주세요. 이미 계정이 있다면 로그인과 이메일 인증만 확인해 주세요. 막히거나 미리 못 하셔도 괜찮습니다. 첫 모임에서 함께 해결하겠습니다.

  1. GitHub 가입 페이지를 열어 주세요. 화면이 영어로 보일 수 있습니다.
  2. 자주 확인하는 이메일 주소를 입력하고 안내에 따라 가입을 진행해 주세요. 구글 이메일을 사용해도 됩니다. 화면에 따라 Google 계정으로 가입하는 방법을 선택할 수도 있습니다.
  3. 비밀번호를 만드는 경우 다른 사이트에서 쓰지 않는 안전한 비밀번호를 정해 주세요. 비밀번호는 다른 사람에게 보내지 않습니다.
  4. 사용자 이름(Username)을 정해 주세요. 공개 주소에 들어갈 수 있으니 기억하기 쉬운 영문 이름으로 정하면 좋습니다. 이미 사용 중이면 다른 이름을 시도해 주세요.
  5. 화면에 사람인지 확인하는 문제가 나오면 안내에 따라 풀어 주세요. 가입 화면의 순서나 표시 내용은 달라질 수 있습니다.
  6. 가입에 사용한 이메일을 열고 GitHub에서 보낸 인증 메일의 안내에 따라 인증해 주세요. 메일이 보이지 않으면 스팸함도 확인해 보세요.
  7. GitHub에 로그인되는지 확인해 주세요. 요금제를 고르는 화면이 나오면 무료인 GitHub Free를 선택하면 됩니다.

공용 노트북을 사용할 때는 가입한 이메일에 접근하거나 로그인 확인을 할 수 있도록 준비해 주세요. 사용을 마칠 때는 GitHub와 이메일에서 로그아웃해 주세요.

인증 메일을 다시 받고 싶다면 GitHub의 Settings → Emails에서 Resend verification email을 누를 수 있습니다. 자세한 내용은 GitHub 공식 가입 안내를 참고하세요.

1. 어디서부터 시작할까요? 12~22분

Google AI Studio로 만들기: Google AI Studio에 로그인하고 Build에서 아래 요청을 입력합니다. 생성된 미리보기의 버튼을 눌러 보고, 바꾸고 싶은 점이 있으면 대화창에 요청해 보세요. 화면과 메뉴 이름은 계정이나 서비스 변경에 따라 다를 수 있습니다.

초등학교 수업에서 쓸 번호 뽑기 앱을 만들어 줘. 1부터 입력한 숫자까지 무작위로 하나를 뽑고 결과를 크게 보여 줘. 아이패드에서도 잘 보이게 해 줘. 학생 이름, 로그인, API 키, 서버 없이 동작하게 해 줘.

배포용 코드 준비: Build는 여러 파일로 된 프로젝트를 만들 수 있습니다. 미리보기가 된다고 바로 GitHub Pages에서 실행되는 것은 아닙니다. AI에게 “방금 만든 앱을 CSS와 자바스크립트를 포함한 독립적인 index.html 한 파일로 다시 작성하고 전체 코드를 보여 줘. 외부 라이브러리와 서버는 사용하지 마.”라고 요청하세요. 코드가 완전한 HTML인지 확인하고 복사합니다. 한 파일로 준비하기 어렵거나 시간이 부족하면 아래 예시 앱을 사용하세요.

예시 앱으로 시작하기: 아직 만들고 싶은 앱이 떠오르지 않아도 괜찮습니다. 퀴즈 판을 열어 실행해 보고 코드 전체 복사를 누르세요. 번호 뽑기·모둠 나누기·타이머나 낱말 카드·빙고판을 골라도 됩니다.

이미 만든 화면으로 시작하기: Google AI Studio나 제미나이 캔버스에서 만든 화면의 전체 코드를 복사합니다. index.html 하나로 실행되는 HTML 코드인지 확인해 주세요. 준비하지 못했거나 잘 모르겠다면 예시 앱으로 시작해도 좋습니다.

예시 앱의 입력 내용은 저장되지 않습니다. 직접 만든 코드에 외부 서비스 연결, 로그인, API 키나 별도 파일이 필요하다면 함께 확인하고, 오늘은 예시 앱으로 먼저 연습해 보세요.

2. GitHub에 올리기 22~47분

진행자의 화면을 보며 한 단계씩 함께 해 봅니다. 영어 버튼 이름은 GitHub 화면에 그대로 표시됩니다.

  1. 저장소 만들기: GitHub에 로그인한 뒤 오른쪽 위 + → New repository를 누릅니다. 저장소는 앱 파일을 담는 공간입니다.
  2. 이름 정하기: Repository name에 영문 이름(예: my-class-app)을 입력합니다. Public을 선택하고 Add a README file을 체크한 뒤 Create repository를 누릅니다.
  3. 파일 만들기: 만들어진 저장소에서 Add file → Create new file을 누릅니다. 파일 이름에 모두 소문자로 index.html을 입력합니다.
  4. 코드 붙여넣기: 큰 편집 칸에 앞에서 복사한 전체 코드를 붙여넣습니다. 학생 정보, 비밀번호, API 키가 들어 있지 않은지 확인합니다.
  5. 저장하기: Commit changes를 누르고 확인 창이 나오면 다시 Commit changes를 누릅니다. 저장소에 index.html이 보이면 됩니다. Commit은 변경 내용을 저장하는 것입니다.
  6. 공개 주소 만들기: 저장소의 Settings → Pages로 이동합니다. Build and deployment의 Source에서 Deploy from a branch를 고르고, Branch에서 main과 /(root)를 선택한 뒤 Save를 누릅니다.
  7. 주소 열기: 잠시 기다렸다가 Pages 화면에 나타나는 주소를 엽니다. 보통 https://아이디.github.io/저장소이름/ 모양입니다. 화면이 열리면 버튼도 눌러 봅니다.

주소가 바로 나타나지 않거나 화면이 바뀌지 않으면 잠시 기다린 뒤 새로고침하세요. 자세한 설명은 배포 가이드, 막혔을 때는 문제 해결을 참고하거나 손을 들어 주세요.

3. 한 번 고쳐 보기 47~55분

  1. GitHub 저장소에서 index.html을 열고 연필 모양 Edit this file을 누릅니다.
  2. 제목이나 퀴즈 문제의 글자 한 곳을 바꿉니다. 따옴표와 괄호는 지우지 않도록 살펴보세요.
  3. Commit changes를 누르고 확인 창에서도 저장합니다. 잠시 기다린 뒤 같은 공개 주소를 새로고침하여 바뀐 내용을 확인합니다.
오늘의 성공 확인 공개 주소에서 앱이 열리나요? 버튼이 작동하나요? 바꾼 글자가 보이나요? 아직 되지 않아도 괜찮습니다. 막힌 단계부터 함께 확인합니다.

4. 마무리와 다음 시간 55~60분

내 공개 주소와 GitHub 저장소를 다음에도 찾을 수 있도록 북마크하거나 개인 메모에 적어 두세요. 비밀번호는 공유하거나 메모에 함께 적지 않습니다. 오늘 끝내지 못한 부분은 함께 확인하거나 나중에 이어서 해도 됩니다.

2회차에는 오늘의 앱을 이어서 고치거나 직접 만든 앱을 올리고, AI에 수정을 요청하는 방법과 공개할 때 지킬 점을 살펴봅니다. 다음에 바꾸고 싶은 점 한 가지를 생각해 오세요.

꼭 지켜 주세요 학생 개인정보(이름·번호·평가 결과)와 API 키·비밀번호는 앱 코드와 저장소에 넣지 않습니다. GitHub Pages는 공개 주소이고, 배포하면 코드 전체가 누구에게나 보입니다.

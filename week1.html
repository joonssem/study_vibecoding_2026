1회차. 환경 구축 연습과 시작점 정하기

빈 앱을 인터넷 주소로 열어 보는 것이 오늘의 목표입니다.

첫 모임 전에: GitHub 가입하기

11월 9일까지 무료 계정을 만들어 주세요. 이미 계정이 있다면 로그인과 이메일 인증만 확인해 주세요. 막히거나 미리 못 하셔도 괜찮습니다. 첫 모임에서 함께 해결하겠습니다.

  1. GitHub 가입 페이지를 열어 주세요. 화면이 영어로 보일 수 있습니다.
  2. 자주 확인하는 이메일 주소를 입력하고 안내에 따라 가입을 진행해 주세요. 구글 이메일을 사용해도 됩니다. 화면에 따라 Google 계정으로 가입하는 방법을 선택할 수도 있습니다.
  3. 비밀번호를 만드는 경우 다른 사이트에서 쓰지 않는 안전한 비밀번호를 정해 주세요. 비밀번호는 다른 사람에게 보내지 않습니다.
  4. 사용자 이름(Username)을 정해 주세요. 공개 주소에 들어갈 수 있으니 기억하기 쉬운 영문 이름으로 정하면 좋습니다. 이미 사용 중이면 다른 이름을 시도해 주세요.
  5. 화면에 사람인지 확인하는 문제가 나오면 안내에 따라 풀어 주세요. 가입 화면의 순서나 표시 내용은 달라질 수 있습니다.
  6. 가입에 사용한 이메일을 열고 GitHub에서 보낸 인증 메일의 안내에 따라 인증해 주세요. 메일이 보이지 않으면 스팸함도 확인해 보세요.
  7. GitHub에 로그인되는지 확인해 주세요. 요금제를 고르는 화면이 나오면 무료인 GitHub Free를 선택하면 됩니다.

공용 노트북을 사용할 때는 가입한 이메일에 접근하거나 로그인 확인을 할 수 있도록 준비해 주세요. 사용을 마칠 때는 GitHub와 이메일에서 로그아웃해 주세요.

인증 메일을 다시 받고 싶다면 GitHub의 Settings → Emails에서 Resend verification email을 누를 수 있습니다. 자세한 내용은 GitHub 공식 가입 안내를 참고하세요.

분활동
0~5오프닝: 3주 흐름, 배포된 앱 예시
5~12도구 확인: 쓰는 AI 서비스와 유료 여부를 확인하고 도구 안내 표로 쓸 도구 정하기
12~22시작점 정하기: 해커톤 작품의 부족한 점 1~3가지, 또는 새 앱의 교실 문제 한 문장(누가/언제/무엇이 되면 쓰는가)
22~47환경 구축 연습: GitHub 가입 확인 → 저장소 → 빈 앱 index.html → Pages 켜기 → 주소 열기 (배포 가이드)
47~55수정 반영 연습: 제목 글자를 바꿔 Commit → 같은 주소에 반영 확인
55~60숙제 안내

오늘의 성공 기준

제목 글자가 인터넷 주소로 보이면 성공입니다. 밋밋해 보여도 정상입니다.

숙제

  1. 시작점으로 AI 도구에서 기능 1가지를 고도화(해커톤)하거나 첫 화면을 만들기(새 앱). 완성한 전체 코드를 메모에 보관해 둡니다.
  2. 빈 앱 배포가 끝나지 않았다면 마무리합니다.
  3. (선택) 설치형 도구를 설치하고 로그인해 둡니다.
꼭 지켜 주세요 학생 개인정보(이름·번호·평가 결과)와 API 키·비밀번호는 앱 코드와 저장소에 넣지 않습니다. GitHub Pages는 공개 주소이고, 배포하면 코드 전체가 누구에게나 보입니다.

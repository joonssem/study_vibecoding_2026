배포 가이드

GitHub Pages로 내 index.html을 공개 주소로 올립니다.

처음 한 번: 7단계

  1. github.com에 로그인하고 오른쪽 위 + 를 눌러 New repository를 고릅니다.
  2. 저장소 이름을 입력합니다(예: my-app). Public을 고르고 Add a README file을 체크한 뒤 Create repository를 누릅니다.
  3. Add file → Create new file을 누르고 파일 이름에 index.html을 입력합니다.
  4. 코드를 붙여넣습니다. 첫 배포는 아래 빈 앱 코드를 쓰고, 이후에는 내 앱 코드로 바꿉니다.
  5. 초록색 Commit changes를 누릅니다.
  6. Settings → Pages로 가서 Branch를 main으로 고르고 Save를 누릅니다.
  7. 1~2분 뒤 위쪽에 나타난 주소(아이디.github.io/저장소이름)를 새 탭에서 엽니다.

첫 배포용 빈 앱 코드

<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>우리 교실 앱</title>
</head>
<body>
  <h1>우리 교실 앱</h1>
  <p>곧 내 앱이 여기에 나타납니다!</p>
</body>
</html>
성공 기준 제목 글자가 인터넷 주소로 보이면 성공입니다. 밋밋해도 정상입니다.

반영 시간

  • 첫 배포: 1~2분 (가끔 더 걸립니다)
  • 이후 수정: 보통 수십 초
  • 안 바뀌어 보이면 Ctrl+Shift+R(강력 새로고침)을 누릅니다.

수정할 때

  1. 같은 저장소에서 index.html을 엽니다.
  2. 연필 아이콘(편집)을 눌러 코드를 바꿉니다.
  3. Commit changes를 누르면 같은 주소에 자동으로 반영됩니다.

체크리스트

  • 파일 이름은 index.html (모두 소문자)
  • 저장소는 Public
  • Pages의 Branch는 main

잘 안 되면 문제 해결을 보세요.

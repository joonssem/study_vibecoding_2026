다음 단계와 심화과정

3주 기본과정(1~3회차)에서 익힌 흐름을 바탕으로, 교실 상황에 맞게 아래 방향으로 발전시킬 수 있습니다.

GitHub Pages와 교실 PC 확장 기준

내 앱에 필요한 것GitHub Pages만으로 되는가추천하는 다음 길
정적 화면, 키·학생 정보 없음된다GitHub Pages 그대로 사용
학생 이름·기록 등 개인정보 저장안 된다 (공개 저장소 위험)교실 PC 로컬 실행 + JSON 파일 저장·불러오기 (.gitignore로 데이터 제외)
앱에 Gemini AI 기능(API 키) 넣기안 된다 (코드 공개로 키 유출)교실/개인 PC .env 보관 + 로컬 실행 또는 서버 중계 구조
여러 사람이 같은 데이터를 함께 봐야 함안 된다구글 시트 + Apps Script 연동
기능을 계속 고치고 이력을 관리하고 싶음된다Google Antigravity + Git (pull → 수정 → push)

심화과정 로드맵 (예정)

이 사이트의 1~3회차 내용은 다음 스터디의 기본과정으로 계속 활용하며, 이후 아래 주제를 다루는 심화과정으로 이어갈 예정입니다.

  • 교실 PC 전용 학급 관리 도구 만들기: 코드는 GitHub로 관리하되, 학생 데이터는 교실 PC에 JSON으로 안전하게 저장·백업하는 실전 앱 완성
  • 안전한 Gemini API 활용 앱: 교육용/개인 Gemini API 키를 .env로 로컬 보관하며 수업 자료 생성·피드백 보조 도구 만들기
  • 공동 데이터 연동: 구글 스프레드시트와 Apps Script를 연결해 여러 기기에서 함께 쓰는 간단한 학급 웹앱 만들기
  • Antigravity 고급 활용: 여러 파일로 나뉜 프로젝트 관리, 규칙·프롬프트 재사용으로 나만의 개발 환경 다듬기
API 키와 학생 데이터는 절대 GitHub에 올리지 마세요 AI 기능이나 학생 기록이 필요하더라도 키와 실제 데이터 파일은 코드·저장소에 넣지 않습니다. .env와 데이터 .json 파일은 반드시 .gitignore에 등록하고 교실/개인 PC에만 보관합니다.
꼭 지켜 주세요 학생 개인정보(이름·번호·평가 결과)와 API 키·비밀번호는 앱 코드와 저장소에 넣지 않습니다. GitHub Pages는 공개 주소이고, 배포하면 코드 전체가 누구에게나 보입니다.

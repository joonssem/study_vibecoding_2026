GitHub Pages는 정적 파일만 올립니다. 앱이 아래 상태가 되면 Pages를 넘어서는 것입니다.

신호Pages로 되는가다음 길
정적 화면, 키·학생 정보 없음된다그대로 사용
여러 사람이 같은 데이터를 봐야 함안 된다구글 시트 + 앱스 스크립트 등 (방향만 소개)
앱에 AI 기능(API 키)을 넣고 싶다안 된다 (코드가 공개되므로 키를 둘 수 없음)서버 쪽을 거치는 구조가 필요합니다. 연수에서는 경고만 합니다.
코드 수정이 잦다된다안티그래비티 등 편집 도구
API 키는 절대 코드에 넣지 마세요 AI 기능을 넣고 싶어도 키를 index.html에 적으면 누구나 볼 수 있습니다. 필요하다면 그 방법은 연수 후 따로 상의합니다.
꼭 지켜 주세요 학생 개인정보(이름·번호·평가 결과)와 API 키·비밀번호는 앱 코드와 저장소에 넣지 않습니다. GitHub Pages는 공개 주소이고, 배포하면 코드 전체가 누구에게나 보입니다.

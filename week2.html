2회차. 내 앱 배포하고 점검하기

내가 만든 앱 코드를 같은 주소에 올리고, 공개해도 되는지 점검합니다.

분활동
0~10숙제 점검, 막힌 사람 도움
10~25내 앱 코드로 index.html 교체 → Commit → 반영 확인 (제미나이·구글 AI Studio 코드를 올려 배포)
25~35미니 강의: 잘 고치는 요청법, 오류 문구 붙이기, 되돌리기
35~45개인정보·API 키·공개 원칙 점검
45~55점검 결과 반영 후 재배포, 짝 점검(열림·작동·오류·개인정보)
55~60숙제 안내

짝 점검 네 가지

  1. 열림: 공개 주소가 열리는가
  2. 작동: 버튼과 기능이 의도대로 움직이는가
  3. 오류: 빈 화면이나 오류 문구가 없는가
  4. 개인정보: 학생 이름·번호·평가 결과, API 키·비밀번호가 코드에 없는가
꼭 지켜 주세요 학생 개인정보(이름·번호·평가 결과)와 API 키·비밀번호는 앱 코드와 저장소에 넣지 않습니다. GitHub Pages는 공개 주소이고, 배포하면 코드 전체가 누구에게나 보입니다.

숙제

  1. 앱을 우리 반에서 실제로 써 보고 학생·동료의 반응을 한 줄 기록합니다.
  2. 고칠 점을 1가지 정해 옵니다.
